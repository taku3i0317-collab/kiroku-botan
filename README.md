# kiroku-botan

Claude Code の MOD。右のペインに生活の記録のボタン（例：朝・昼・夜・洗濯・ごみ）を並べ、名前を押すと、いまの時刻で記録の合図を送る。記録そのものは秘書のフォルダ（例：`notes`）の記録のフック（`journal/記録/` に書く）が書く。ボタンと目安は、そのフォルダの `status/生活.md`（定例・声かけ・間隔・ボタンの表）と記録のフックから読む。ペインは自動では開かない。`/kiroku` と打ったときだけ開く（`status/生活.md` の無いフォルダでは中身が出ない）。ペインのいちばん上には、次の予定（今日の定例か、7日以内の締め切り）までの残り時間を大きく出す。

秘書のテンプレート（secretary-template）の「記録のボタン（任意）」で使う形。組織図（soshiki-zu）にも同じ記録のボタンが入っているので、組織図を使うならこちらは無くてもよい。

## 使い方

| したいこと | 押す所 | 送る合図 |
|---|---|---|
| いま、した | 行の名前（1回） | `朝` |
| 少し前にした | 行の右の「時刻・なし」→ −30分・−10分・−5分 →「この時刻で記録」 | `朝 7:40` |
| しなかった | 行の右の「時刻・なし」→「今日はなし」（言い方は「## ボタン」の表で項目ごとに変えられる。例：食べなかった） | `朝 なし` |
| 運動の長さを付ける | 運動の「時刻・なし」→ 長さ →「この時刻で記録」 | `運動 12:10 20分` |
| 記録を直す | 済の行（名前でも「直す」でも）→ 時刻を選び直すか「なし」 | あとの行が勝つ |

- 済の行は、押しても二重に送らない（直す欄が開くだけ）。
- 「なし」の行は、横線のアイコンと「なし（08:10）」。色は変えない（目安超えの橙は「まだ」のときだけ）。
- 「なし」は今日の行を埋めるので、その項目の声かけは出ない。洗濯・ごみなどの「何日ごと」は、やった日だけで数える（今日「なし」でも、明日はまた目安超えになりうる）。

## ボタンの項目を決める

MOD の中に、決まった項目は入っていない。ボタンは次の順で作る:

1. `status/生活.md` に「## ボタン」の表があれば、その順で出す。「まとまり」が見出し、「なしの言い方」が「しなかった」のボタンの文字（空なら「今日はなし」）

   ```
   ## ボタン
   | 項目 | まとまり | なしの言い方 |
   |---|---|---|
   | 朝 | ごはん | 食べなかった |
   | 昼 | ごはん | 食べなかった |
   | 夜 | ごはん | 食べなかった |
   ```

2. 表が無ければ、記録のフック（`.claude/scripts/life-log.ps1`）が受け取る合図の一覧（`$items = @('朝','昼','夜')`）を、見出し「毎日」で出す
3. どちらのあとにも、`status/生活.md` の「間隔」の表の項目（例：洗濯・ごみ）を足す（見出しは「何日かごと」。「## ボタン」の表に書けばそのまとまりに入る）

ボタンを押して送る合図は、記録のフックが受け取る物だけにする（「## ボタン」の表に書く項目も、フックの合図か「間隔」の表の項目にする）。

## いちばん上のカウントダウン

例：

```
準備開始
あと 0:09   16:40
```

- 出す物：次の予定 **1つだけ**。名前（見出しの大きさ）と「あと H:MM」（いちばん大きい字）、右に小さく予定の時刻。24時間より先なら「あと 1日 6時間」と、日付つきの時刻（`10/24（土）23:59`）。
- 予定の元（新しいデータの置き場は作らない）：
  - 今日の定例：`status/生活.md` の「定例」表。「すること」か「時刻の目安」に `17:20 に家を出る` `16:40 に準備開始` のような「時刻 に 〜」があれば、その時刻と「に」のあとの言葉（括弧の前まで）を予定にする。
  - 締め切り：`status/締め切り.md` の「予定」表（`| 日付 | 部門 | やること | 状態 |`）。前からの形の `status/学業.md` の「個別」表（`| 日付 | 科目 | 出すもの | 状態 |`）もあれば読む。今日から7日以内で、状態が `済` でない行。時刻は `23:59まで`・`16:50まで` から取り、書いていなければその日の 23:59。
  - 「その週の土 23:59」のような日付の無い書き方は入れていない。入れたいときは、秘書が表に日付の行を足せば出る。
- 時刻を過ぎたら次の予定に切り替わる（1分ごとに読み直す）。予定が無いときは何も出さない。
- 残り30分以内で橙（ほかと同じ「合図の色」）。音や通知は出さない。
- 表は見出しの名前で列を探すので、列の順が変わっても読める。

## 「しなかった」とフック

フックの形「合図 [時刻] [短いメモ]」のメモに `なし` を入れるだけで、そのまま記録される（フックは変えなくてよい）:

```
- 2026-10-23 16:33 朝 なし
- 2026-10-23 16:33 洗濯 なし
```

記録の言葉は事実だけの `なし`。ボタンの言い方もそれに合わせ、責める言い方はしない。

## なぜこの押し方か

前（0.1.0）は「行を押す → 時計が開く → 時刻を合わせる → 記録する」で、いちばん多い「いま、した」にも2回押す必要があり、押したのに記録されない（時計が開くだけ）のが分かりにくかった。考えた案：

1. **名前を押す＝いまで記録、右の「時刻・なし」で詳しく**（採用）：いちばん多い場合が1回。詳しい物は、何ができるかがボタンの文字に書いてある。
2. 名前を押すと「いま／時刻／なし」の3つが出る：毎回2回になる。
3. 行ごとに「した」「なし」のボタンを2つ並べる：1回で済むが、7行×2で14個並び、細いペインで詰まる。「なし」は「した」より少ないので、1段奥でよい。
4. 押してから数秒の「取り消し」：送った合図はフックが追記するので消せない。直すときは打ち直し（あとの行が勝つ）になるため、済の行を押すと直す欄が開くようにした。

ペインの一番上に「名前を押すと、いまの時刻で記録」と1行だけ書いておく。

## 組織図（soshiki-zu）と並ぶとき

- きろくのペインは自動では開かないので、ふだんは組織図だけが右に出る（組織図の下にも同じ読み方の記録のボタンがある）。`/kiroku` で開くと、組織図と別のタブで並ぶ。
- きろくの行は、ペインが細いと「時刻・なし」が次の行に回る（折り返す）ので、文字が切れない。

## 入れ方

秘書のフォルダ（`status/生活.md` と記録のフックがある所）で Claude を開いて使う。それが無い所では何も記録されない。

ターミナルの Claude Code で:

```
/plugin install kiroku-botan --marketplace taku3i0317-collab/kiroku-botan
```

シェルから:

```
claude plugin install kiroku-botan --marketplace taku3i0317-collab/kiroku-botan
```

デスクトップアプリ（`/plugin` が使えない所）: 入力欄の横の + → Plugins → Add marketplace に `taku3i0317-collab/kiroku-botan` → Add plugin。

入れたあと、秘書のフォルダのセッションを開き直すか `/reload-plugins` のあと、`/kiroku` と打つとペインが出る（自動では開かない）。

直しながら使うとき（フォルダから読む入れ方。直したら `claude plugin update kiroku-botan@kiroku-botan`）:

```
git clone https://github.com/taku3i0317-collab/kiroku-botan.git
claude plugin marketplace add ./kiroku-botan
claude plugin install kiroku-botan@kiroku-botan
```

自動のテスト: `claude plugin test .`
